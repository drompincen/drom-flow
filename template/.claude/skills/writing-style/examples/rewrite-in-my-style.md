# Rewrite a draft using my writing samples

Paste this into Claude, replacing the file paths with your own. Adjust the skill path if it is installed elsewhere.

```text
Use the writing-style skill at .claude/skills/writing-style/SKILL.md.

My writing samples:
- path/to/my-email.txt
- path/to/my-letter.md
- path/to/my-article.md

Text to rewrite:
- path/to/ai-draft.md

Learn my writing style from the samples: word choice, sentence
rhythm, tone, directness, paragraph structure, and punctuation.

Rewrite the target text in my style. Remove AI slop, filler,
canned phrases, repetition, fake warmth, and inflated language.
Make it sound like something I would actually write.

Preserve the target's meaning, facts, details, uncertainty, and
commitments. Use the samples only for style; don't import their
facts or opinions. Don't treat the AI draft as a style sample.

Return only the rewritten text.
```
