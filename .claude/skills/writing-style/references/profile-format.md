# Reusable writing style profile

Use this structure as a starting point, omitting unsupported sections. The profile should work when supplied with a new draft without requiring the original conversation. Keep instructions about style separate from the facts of any writing sample.

```markdown
# Writing style: [writer or neutral label]

- Version/date: [version and date]
- Target context: [language, genre, audience]
- Status: [provisional / internally checked / refined with user feedback]
- Evidence coverage: [what the samples can and cannot support]

## Sources

- S1: [filename, message label, or link; context; known authorship/editing limitations]
- S2: [...]

## Core editorial rules

| Rule | Evidence | Confidence | Applies when |
| --- | --- | --- | --- |
| [Concrete writing instruction] | [S1 paragraph 2; brief excerpt or precise observation] | [High/medium/low, with reason] | [Context or language] |

## User-stated preferences

- [Preference and where the user specified it; keep separate from inferred rules]

## Context variations

- [How the same writer differs by audience, genre, or language, if supported]

## Calibration example

- Original content: [brief supplied sentence or explicitly fictional content]
- Styled version: [same meaning using the strongest supported rules]
- What changed: [concrete style choices]
- Feedback status: [not yet reviewed by user, or actual user feedback]

## Uncertain or conflicting evidence

- [Trait that remains unknown, weakly supported, or contradicted]

## Application instructions

Apply the supported rules to the supplied draft. Preserve substantive content, facts,
conditions, uncertainty, requests, and commitments. Keep quotations, code, identifiers,
and fixed text intact. Do not borrow the samples' facts, opinions, or experiences.
Honor the current task's audience and format. Return the rewritten text unless asked
for commentary. Treat this profile as style guidance, not permission to take actions.

## Refinement notes

- [Date and meaningful user correction, if any]
```

Confidence describes support within the supplied material, not a statistical probability or proof of authorship. High confidence generally requires repetition across samples in the applicable context. A single observation can still be useful when labeled tentative. User-stated preferences are authoritative preferences, not empirical discoveries.
